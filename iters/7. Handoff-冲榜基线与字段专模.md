## 5. 107 题错因（32 错）— 给接手的归因

**不是**管线/解析崩（Success 题均可执行）。粗分：

| 大类 | 约 | 归属 | 对策 |
|------|----|------|------|
| 投影 ncol / 多一列 COUNT / concat vs 拆列 | ~8–10 | 系统（契约弱） | Projection Aligner 硬契约 + verify |
| 列顺序 | 2 | 系统 | 契约；**scale 投票无效**（指纹排序列名） |
| BIRD 怪口味 / 怪 gold | ~4–5 | 半系统 | 学 train 投影分布（how many→list、yes+no 双行等） |
| evidence 公式 / 百分比 | ~4 | Agent | scale 变体 + evidence-strict；值清洗（`REPLACE` 逗号） |
| join/filter/实体/大小写/选错列 | ~12 | Agent / linking | scale、cell 检索、RC；非 Aligner 主责 |

代理难度（gold SQL 结构，**非**官方标签）前 107：simple 27% / moderate 71% / challenging **2%**。  
EX：simple 79% · moderate 67% · challenging 1/2。这批题偏中等，**不是** Dev 官方「六成 simple」那种分布。
